# Flutter Runner

This skill runs the Flutter application on Windows with verbose output to verify that code changes build and run correctly.

## When to Use
- After making any code changes to the Flutter application
- When you need to test the application on Windows
- When you want to see verbose build output for debugging

## How It Works
1. Executes `flutter run -d windows -v` command
2. Builds the Flutter application for Windows
3. Launches the application on Windows
4. Provides verbose output for debugging purposes

## Usage
Invoke this skill after making code changes to ensure the application still builds and runs correctly on Windows.

## Example
After modifying the book_card.dart file, invoke this skill to verify the changes work as expected on Windows.
