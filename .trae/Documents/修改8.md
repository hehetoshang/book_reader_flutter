根据您的情况，我推荐使用**包装器组件和应用程序级别的本地化相结合**的方案。这个方案不需要修改 EPUB 模块的核心代码，同时能够提供良好的国际化体验。

## 推荐方案的实现步骤

### 1. **设置应用程序级别的本地化**

**第一步：添加依赖**
在 `pubspec.yaml` 中添加本地化依赖：
```yaml
dependencies:
  flutter:
    sdk: flutter
  flutter_localizations:
    sdk: flutter
  intl: ^0.18.0
```

**第二步：创建本地化文件**
在 `lib/l10n/` 目录下创建本地化文件：

- `app_en.arb` (英文)：
  ```json
  {
    "tableOfContents": "Table of Contents",
    "fontSize": "Font Size",
    "readingMode": "Reading Mode",
    "theme": "Theme",
    "loading": "Loading EPUB...",
    "errorLoading": "Error loading EPUB"
  }
  ```

- `app_zh.arb` (中文)：
  ```json
  {
    "tableOfContents": "目录",
    "fontSize": "字体大小",
    "readingMode": "阅读模式",
    "theme": "主题",
    "loading": "加载 EPUB...",
    "errorLoading": "加载 EPUB 错误"
  }
  ```

**第三步：配置应用程序**
在 `main.dart` 中配置本地化：
```dart
import 'package:flutter/material.dart';
import 'package:flutter_localizations/flutter_localizations.dart';
import 'package:flutter_gen/gen_l10n/app_localizations.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Book Reader',
      localizationsDelegates: AppLocalizations.localizationsDelegates,
      supportedLocales: AppLocalizations.supportedLocales,
      home: const ShelfScreen(),
    );
  }
}
```

### 2. **创建包装器组件**

**第一步：创建本地化包装器**
```dart
import 'package:flutter/material.dart';
import 'package:flutter_gen/gen_l10n/app_localizations.dart';
import 'epub_reader_screen.dart';

class LocalizedEpubReader extends StatelessWidget {
  final String bookId;

  const LocalizedEpubReader({super.key, required this.bookId});

  @override
  Widget build(BuildContext context) {
    final locale = Localizations.localeOf(context);
    final localizations = AppLocalizations.of(context);
    
    return Directionality(
      textDirection: _isRtlLanguage(locale.languageCode) 
          ? TextDirection.rtl 
          : TextDirection.ltr,
      child: Builder(
        builder: (context) {
          // 这里可以添加更多本地化逻辑
          return EpubReaderScreen(bookId: bookId);
        },
      ),
    );
  }

  // 检查是否为 RTL 语言
  bool _isRtlLanguage(String languageCode) {
    return ['ar', 'he', 'fa', 'ur', 'ps', 'sd'].contains(languageCode);
  }
}
```

**第二步：使用包装器组件**
在导航时使用 `LocalizedEpubReader` 替代直接使用 `EpubReaderScreen`：
```dart
// 之前的代码
AppRouter.goToEpubReader(context, book.id);

// 修改后的代码
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => LocalizedEpubReader(bookId: book.id),
  ),
);
```

### 3. **处理特殊语言需求**

**RTL 语言支持**
如上面的代码所示，使用 `Directionality` 组件为 RTL 语言设置正确的文本方向。

**字体支持**
为不同语言设置合适的字体：
```dart
class LocalizedEpubReader extends StatelessWidget {
  // ...
  
  @override
  Widget build(BuildContext context) {
    final locale = Localizations.localeOf(context);
    
    return Theme(
      data: Theme.of(context).copyWith(
        textTheme: Theme.of(context).textTheme.apply(
          fontFamily: _getFontFamily(locale.languageCode),
        ),
      ),
      child: Directionality(
        // ...
      ),
    );
  }

  String _getFontFamily(String languageCode) {
    switch (languageCode) {
      case 'zh':
        return 'Noto Sans SC'; // 中文字体
      case 'ja':
        return 'Noto Sans JP'; // 日文字体
      case 'ko':
        return 'Noto Sans KR'; // 韩文字体
      default:
        return 'Roboto'; // 默认字体
    }
  }
}
```

**本地化阅读器设置**

```dart

  Widget build(BuildContext context) {

```

## 方案的优势

1. **无需修改 EPUB 模块**：不需要修改 Katbook EPUB Reader 的核心代码
2. **统一管理**：在应用程序层面统一管理所有本地化资源
3. **灵活性高**：可以根据需要扩展本地化支持
4. **用户体验好**：提供与系统语言一致的界面
5. **实现简单**：相比其他方案，实现相对简单直接

这个方案能够满足您的国际化需求，同时保持代码的可维护性和扩展性。
